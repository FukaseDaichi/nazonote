# nazo-digest — 謎解きnote 日次ダイジェスト作成

収集済み候補を **AIが全件評価 → おすすめ選抜 → フランクに記事化** する。機械スコアは下ごしらえに過ぎず、採点・選抜・執筆はすべてあなた（AI）が行う。

## 入力（読み込む）
- `state/candidates_top.json` … 候補プール。各要素: `key`/`title`/`url`/`meta`/`marker`/`hashtags`/`description`(note原文)/`body_excerpt`(本文冒頭)/`mech_score`。
- `state/today.txt` … 本日の日付（`YYYY-MM-DD`）。出力ファイル名に使う。
- `state/weights_learned.json`（あれば）… ユーザーが過去に [x] で示した関心タグ→重み。選抜の個人化に使う。

## 手順

### A. 全候補の内容確認＆採点
`candidates_top.json` の **全件** について、title・tags・description・body_excerpt から内容を判断し、各記事に付ける:
- `ai_score`: 0–100。謎解きとしての面白さ・質・読む価値、そしてユーザーの関心タグ(weights_learned)との適合を総合。
- `genre`: 次のいずれか — `考察` / `一枚謎` / `制作` / `解説` / `推理小説` / `脱出公演` / `感想・レポ` / `宣伝・告知` / `無関係`。
- `gist`: 「どんな記事か」を **1文** で。

優先・抑制の方針:
- 高評価: 考察系、一枚謎・自作謎などの作品、謎の制作/解説、良質な推理・暗号もの。ユーザー関心タグに合うもの。
- 低評価/除外: 単なるイベント感想・参加レポ、宣伝のみ、謎解きとほぼ無関係なのにタグだけ付いた記事（多数タグに紛れた音楽/日記等）。

→ `state/assessments.json` に書き込む:
```json
{ "assessed": [ { "key": "string", "ai_score": 0, "genre": "string", "gist": "string" } ] }
```

### B. おすすめ選抜
`ai_score` を主軸に、ジャンルの多様性も少し意識して **おすすめ最大10本** を 1〜10位でランク付け。良いものが10本に満たなければ無理に埋めない（5〜9本でよい）。各記事に:
- `blurb`: 「こんな記事だったよ！」とフランクに紹介する1〜2文。
- `reason`: どんな人におすすめかを一言。

→ `state/selection.json` に書き込む:
```json
{ "intro": "全体の総評(フランク・2〜3文)", "picks": [ { "rank": 1, "key": "string", "blurb": "string", "reason": "string" } ] }
```

### C. 記事を執筆（メイン成果物）
`state/today.txt` の日付を読み、`daily/<日付>-osusume.md` を **フランクな語り口** で書く。友だちに「今日はこんなのがあったよ！」と話すトーン（です/ます混じりの砕けた文体、絵文字も少々OK）。堅い要約調にしない。

各記事ブロックは、対応する候補の `meta` と `marker` を **そのまま流用** すること（`marker` は学習用なので一字一句コピーして checkbox 行に置く）。書式:

```markdown
# 🧩 今日の謎解きnote、こんなのあったよ！ — <日付>

<intro：今日はどんな日だったか、フランクに2〜3文>

---

## 🥇 1位 [<title>](<url>)
<blurb：こんな記事だったよ！とフランクに>
👉 <reason：どんな人におすすめか>
`<meta>`
- [ ] 気になる <marker>

## 🥈 2位 …（以下、選抜した本数だけ続ける。3位以降は ## 3位 のように番号見出しで）
```

最後に、1〜2文の「今日のひとこと」で締めると良い。

## 制約
- 触れてよいファイルは上記の入出力のみ。候補に無い記事を創作しない。`key`/`url`/`marker` は入力の値を改変しない。
- `assessments.json` / `selection.json` は厳密なJSON（末尾カンマ・コメント・コードフェンス禁止）。
- 記事(md)は読みやすさ最優先。ただし各推し記事の `- [ ] 気になる <!-- key=... tags=... -->` 行は必ず入れる（学習に使う）。
- 出力は静かに完了してよい（長い説明は不要）。
